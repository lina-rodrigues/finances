# Designing with Web Awesome (Finance app)

Canonical skill lives at [`skills/webawesome-design/SKILL.md`](../../../skills/webawesome-design/SKILL.md). Load references from [`skills/webawesome-design/references`](../../../skills/webawesome-design/references).

## Rules

1. Prefer `wa-*` + layout utilities; prefer patterns.
2. Full-page `<wa-page>` shell — no PhoneShell.
3. Theme: `wa-theme-default wa-palette-rudimentary`.
4. Minimal custom CSS.
5. Close custom element tags.
6. npm Pro — not CDN.
