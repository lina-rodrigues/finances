# Web Awesome (Finance app)

This app loads **Web Awesome Pro via npm** (`@web.awesome.me/webawesome-pro`).

- Theme classes on `<html>`: `wa-theme-default wa-palette-rudimentary` (+ `wa-light` / `wa-dark`)
- Package styles: themes/default, color/palettes/rudimentary, utilities, native
- Docs: https://webawesome.com/docs/
- Components: https://webawesome.com/docs/components/
- React: https://webawesome.com/docs/frameworks/react
- Full API references: see `references/` (symlinked from the npm package)

**Always use closing tags** (`<wa-input></wa-input>`, never `<wa-input />`).

Companion: **webawesome-design** for layout, theming, and composition.
